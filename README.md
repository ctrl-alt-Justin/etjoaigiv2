# Etjoaigi Trading FurnitureOps Dashboard

A responsive, browser-based inventory intelligence dashboard for Etjoaigi Trading, a second-hand furniture buying and selling company.

## Included modules

- Standardized product evaluation and automated product/category naming structure
- Centralized master inventory table with fuzzy search, multi-attribute filtering, sorting, lifecycle status tags, unit counts, cost values, and asking values
- Policy-driven valuation and markdown calculator with protected cost-floor logic
- 5-step structured intake wizard with required office-furniture attributes, inspection criteria, photo guidance, and publish validation
- Centralized taxonomy tree and valuation rules for controlled vocabulary enforcement
- Analytics panels for vendors, sell-through signals, inventory aging, inflow, sales, revenue, and margin
- Customer-facing product view with condition grade badges, availability, specs, gallery, and share link action
- Listing age monitor with 30/60/90-day markdown alerts and one-click markdown application

## Brand colors

## Run locally

This is a static HTML/CSS/JavaScript prototype. Open `index.html` directly, or run a simple server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
